# Intranet Web Application

React/Vite frontend s PHP API backendem a EntraID autentizací.

## 🏗️ Struktura projektu

```
intranet-web/
├── client/          # React/Vite frontend
├── api/             # PHP REST API backend
└── README.md
```

## 🚀 Quick Start

### Frontend (Development)
```bash
cd client
npm install
npm run dev
```

### Production Build
```bash
cd client
npm run build
```
