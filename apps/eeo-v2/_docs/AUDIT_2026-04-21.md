## 📖 Legenda

### Riziková škála (severity nálezu)
| Ikona | Úroveň | Popis |
|---|---|---|
| 🔴 | **DANGER** | Vysoké riziko — bezpečnostní díra, ztráta dat, nebo kritický výkonnostní problém. Řešit co nejdříve. |
| 🟡 | **CAUTION** | Střední riziko — potenciální zranitelnost nebo znatelný dopad na UX/výkon. Plánovat opravu. |
| 🟢 | **SAFE / OK** | Nízké riziko, best-practice návrh, nebo informativní poznámka. |

### Typ nálezu
| Zkratka | Oblast |
|---|---|
| **SEC** | Security (SQL inj, XSS, CSRF, auth, path traversal, file upload…) |
| **PERF** | Performance (N+1, indexy, bundle, re-rendery, cache) |
| **CODE** | Code quality (konzistence, udržitelnost, dokumentace, refaktor) |
| **CFG**  | Configuration (hardcode, .env hygiena, HTTP hlavičky) |

### Dopad opravy (KLÍČOVÉ!)
Každý nález má anotaci, jak může oprava ovlivnit běh aplikace:

- **INSERT/UPDATE impact** — riziko, že oprava změní/rozbije ukládání dat do DB
- **READ impact** — riziko, že oprava změní/poškodí konzistenci načítání dat
- **Deploy risk** — 🟢 SAFE (lze nasadit bez obav) / 🟡 CAUTION (nutný test na stagingu) / 🔴 DANGER (vyžaduje feature flag, migraci dat, koordinovaný release)

### ID nálezů
Formát `EEO-AUDIT-NNN` — použitelné jako ticket ID.
