🚀 Informace o nové aktualizaci systému EEO v2

Verze 2.34 | březen 2026

✨ Nová verze EEO 2.34

Připravili jsme aktualizaci s novými funkcemi a opravami v modulech Objednávky, Faktury a Roční poplatky.

🆕 Co je nového

Přehled hlavních změn v EEO 2.34:

✓

Upozornění při potvrzení věcné správnosti za jiného - modul Faktury.

✓

Zrušení workflow objednávky kdykoliv.

✓

Přepočet ceny bez DPH na DPH - rychlý přepočet v zaevidování faktury.

✓

Roční poplatky - poznámku v řádku lze upravovat kdykoliv.

✓

Modul Faktury - v SIDEBAR náhledu jsou vidět poznámky z faktury a poznámky z věcné správnosti.

✓

Spisovka - výchozí filtrování je nastaveno na TÝDEN.

✓

Rychlý náhled souboru MSG - pohodlné zobrazení obsahu.

✓

Oprava mazání příloh u objednávek - správné odstranění záznamu a souboru.

✓

Zvýraznění položek filtru - lepší přehled, co a čím je filtrováno.

✓

Oprava prohlížeče příloh - odstraněné problikávání a zavírání na druhý pokus.

✓

Další drobné opravy - zvýšení stability a komfortu práce.
