## 📡 STRUKTURA ENDPOINTU (Order V2 Standard)

### Povinná struktura každého endpointu:

```php
<?php
/**
 * POST - Endpoint popis
 * Endpoint: muj-endpoint/action
 * 
 * @param string $token - Autentizační token (z body)
 * @param string $username - Uživatelské jméno (z body)
 * @param array $data - Data specifická pro endpoint
 * 
 * @return array JSON response {status, data, message}
 */
function handle_muj_endpoint_action($input, $config) {
    // 1️⃣ METODA - pouze POST
    if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
        http_response_code(405);
        echo json_encode([
            'status' => 'error', 
            'message' => 'Pouze POST metoda'
        ]);
        return;
    }

    // 2️⃣ PARAMETRY z body (ne z headers!)
    $token = $input['token'] ?? '';
    $username = $input['username'] ?? '';
    
    if (!$token || !$username) {
        http_response_code(400);
        echo json_encode([
            'status' => 'error', 
            'message' => 'Chybí povinné parametry: token, username'
        ]);
        return;
    }

    // 3️⃣ AUTENTIZACE
    $token_data = verify_token_v2($token);
    if (!$token_data || $token_data['username'] !== $username) {
        http_response_code(401);
        echo json_encode([
            'status' => 'error', 
            'message' => 'Neplatný token nebo uživatel'
        ]);
        return;
    }

    try {
        // 4️⃣ DATABÁZE - PDO + prepared statements
        $db = get_db($config);
        if (!$db) {
            throw new Exception('Chyba připojení k databázi');
        }

        // 5️⃣ TIMEZONE - VŽDY nastavit!
        TimezoneHelper::setMysqlTimezone($db);

        // 6️⃣ BUSINESS LOGIKA - použij konstanty tabulek
        $stmt = $db->prepare("
            SELECT * 
            FROM `" . TBL_OBJEDNAVKY . "` 
            WHERE id = :id 
            AND deleted_at IS NULL
        ");
        $stmt->execute([':id' => $input['id']]);
        $result = $stmt->fetch(PDO::FETCH_ASSOC);

        // 7️⃣ VALIDACE výsledku
        if (!$result) {
            http_response_code(404);
            echo json_encode([
                'status' => 'error',
                'message' => 'Záznam s ID ' . $input['id'] . ' nebyl nalezen'
            ]);
            return;
        }

        // 8️⃣ ÚSPĚŠNÁ ODPOVĚĎ
        http_response_code(200);
        echo json_encode([
            'status' => 'success',
            'data' => $result,
            'message' => 'Data načtena úspěšně',
            'meta' => [
                'timestamp' => date('Y-m-d H:i:s'),
                'version' => VERSION
            ]
        ]);

    } catch (PDOException $e) {
        // 9️⃣ ERROR HANDLING - SQL chyby
        error_log("🔴 SQL Error v muj-endpoint/action: " . $e->getMessage());
        http_response_code(500);
        echo json_encode([
            'status' => 'error',
            'message' => 'Chyba databáze: ' . $e->getMessage(),
            'error_code' => 'DB_ERROR'
        ]);
    } catch (Exception $e) {
        // 🔟 ERROR HANDLING - obecné chyby
        error_log("🔴 Error v muj-endpoint/action: " . $e->getMessage());
        http_response_code(500);
        echo json_encode([
            'status' => 'error',
            'message' => 'Chyba při zpracování: ' . $e->getMessage()
        ]);
    }
}
```

## 🗄️ DATABÁZOVÉ KONVENCE

### Povinné kontroly před SQL query:

#### 1. Konstanty tabulek
```php
// ✅ SPRÁVNĚ - použij konstanty z api.php
$query = "SELECT * FROM `" . TBL_OBJEDNAVKY . "` WHERE id = ?";

// ❌ ŠPATNĚ - hardcoded název tabulky
$query = "SELECT * FROM `25a_objednavky` WHERE id = ?";  // NIKDY!
```

**📋 Hlavní konstanty tabulek:**
```php
define('TBL_OBJEDNAVKY', '25a_objednavky');
define('TBL_UZIVATELE', '25_uzivatele');
define('TBL_FAKTURY', '25a_objednavky_faktury');
define('TBL_SMLOUVY', '25_smlouvy');
define('TBL_ORGANIZACE_VIZITKA', '25_organizace_vizitka');
define('TBL_DODAVATELE', '25_dodavatele');
define('TBL_PRILOHY', '25a_objednavky_prilohy');
```

#### 2. Ověření názvů sloupců
```bash
# ✅ Před použitím sloupce - zkontroluj jeho název:
grep -r "25_organizace_vizitka" lib/*.php | grep "SELECT"

# Výsledek:
# SELECT org.nazev_organizace  ← SPRÁVNÝ název sloupce
# (ne "nazev" nebo "org_nazev")
```

#### 3. Prepared statements (VŽDY!)
```php
// ✅ SPRÁVNĚ - prepared statement
$stmt = $db->prepare("
    SELECT * FROM `" . TBL_FAKTURY . "` 
    WHERE objednavka_id = :order_id 
    AND deleted_at IS NULL
");
$stmt->execute([':order_id' => $orderId]);

// ❌ ŠPATNĚ - SQL injection risk!
$query = "SELECT * FROM faktury WHERE objednavka_id = $orderId";  // NIKDY!
```

#### 4. Timezone helper (VŽDY!)
```php
// ✅ VŽDY nastav timezone na začátku každého endpointu
TimezoneHelper::setMysqlTimezone($db);

// Pak používej české časy správně:
$now = date('Y-m-d H:i:s'); // CZ čas
```
