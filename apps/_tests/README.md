# Test Scripts

Testovací skripty pro ERDMS aplikaci.

## Obsah
- `test-*.php` - PHP testovací skripty pro různé API endpointy
- `test-*.sh` - Shell skripty pro HTTP testování

## Použití
```bash
php test-<nazev>.php
# nebo
./test-<nazev>.sh
```

⚠️ **Pozor:** Tyto skripty jsou pro vývojové účely. Nepoužívat na produkci!
